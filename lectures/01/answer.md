## 宿題

- 取り組んだレベル： 実装 
- やったこと：app/ask.py に --interactive オプションを追加し、会話履歴を保持したまま続けて質問できるように改修した。同じチャットオブジェクトに対して send_message() を繰り返すことで、過去の質問と回答を引き継ぐ構成にした。また、各応答の入力・出力トークン数を表示し、空行で会話を終了できるようにした。
- 結果：コード上では履歴を保持する構造を確認できた。具体的にはuv run python -m app.ask --interactive "私の架空のペットの名前はポポです。覚えてください。"と入力した上で、回答後の 次の質問（空行で終了）> に、続けて"ペットの名前は何でしたか？"と入力したところ、きちんとポポが名前として表示された。
- 気づき・疑問：今回の実装では履歴は実行中だけ保持されるため、プログラムを終了した後も会話を引き継ぐには、履歴をファイルなどに保存する仕組みが必要だと気づいた。
